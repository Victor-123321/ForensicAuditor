What an accusation
looks like

This product is defined by what it refuses to claim: it accuses no one without a graph edge to back it up. The interface has to say the same thing without anyone reading the code, and for that, color cannot be decoration.

Two layers, kept apart on purpose. The theme (color and typography) is interchangeable. Motion is the identity: it has to survive a change of theme. Both live in tokens.css.

01

Color is an argument

Three colors make claims and are used for nothing else. If something is red, there is an edge_id in evidence_trail that backs it; if there is not, it stays amber no matter how convinced the agent is. Green is set only by the SAT, and the graph legend hides it when no company has been cleared: promising a state the data cannot reach is the same lie, only cheaper.

02

All hard data is monospaced

An RFC, a CFDI UUID, an edge id and an amount are things someone will read out loud or copy into an official letter. In monospace they read as evidence you can transcribe; in the same typeface as running text they read as prose.

Nothing appears: it arrives

The system's signature. Everything enters offset, with a 4° slant that straightens as it settles — motion in italics. The asymmetry carries meaning: what the system says enters from the left, what I do enters from the right. Two curves across the whole product, and nothing runs past 600ms.

04

The five step types

The agent's reasoning gets read out of the corner of the eye while someone else is talking, so the five types have to be told apart by shape, not by their label. Conclusion is the strongest, but it is not red: concluding is not proving, and half of these conclusions say nothing was found.

05

You can feel it when you press it

A hard shadow with no blur, like stamped ink. On press, the element sinks into its own shadow in 120ms. The primary action leans 6° toward the cursor; large surfaces never do.

07

Ambience, in three layers

Paper fibers at 7s, a warm glow that breathes at 18s and dust motes between 19 and 36s, all with a negative delay so they are already running on the first frame. Opacity between 0.06 and 0.14, only transform and opacity. Never behind the graph or the case file reading area: there, calm is worth more than texture. It is running behind this page right now.

fibers 7s linear · breathing 18s alternate · motes 19–36s
08

Turning it off is part of the design

prefers-reduced-motion stops every loop and cuts entries down to 10ms — reduced, not removed, because an entry that never runs leaves the content invisible. On top of that, three switches the user controls are saved in localStorage as classes on <html>, so turning a group off never touches the application logic.
